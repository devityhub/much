# Much

Interface web inspirada no Discord, com foco na área de **Amigos**.

## O que tem

- Barra lateral com **Amigos** e **Solicitações de mensagens**
- Abas de amigos: **Disponível**, **Todos**, **Pendentes** e **Adicionar amigo**
- A aba **Bloqueados** não é exibida
- Painel **Ativo agora**, mensagens diretas e estados vazios

## Como rodar

```bash
npm install
npm run dev
```

Abra [http://127.0.0.1:43123](http://127.0.0.1:43123).

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- lucide-react
